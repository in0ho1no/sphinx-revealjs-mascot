必須画像はすべての構成で使い、追加画像は追加アクションで使います。

| ファイル | 区分 | 表情・姿勢 |
| --- | --- | --- |
| `normal.png` | 必須画像 | 目を開けた通常の立ち姿 |
| `blink.png` | 必須画像 | 通常の立ち姿のまま両目を閉じた姿 |
| `sleepy.png` | 必須画像 | 目を閉じ、頭をわずかに傾けた眠そうな姿 |
| `surprise.png` | 必須画像 | 目を丸くし、くちばしを開けて驚いた姿 |
| `happy.png` | 追加画像 | 目を細めて笑い、両翼を広げて喜ぶ姿 |
| `tilt.png` | 追加画像 | 首を大きくかしげた姿 |
| `trouble.png` | 追加画像 | 汗を浮かべた困り顔で、前かがみになった姿 |
| `proud.png` | 追加画像 | 胸を張り、きりっとした目つきで得意げな姿 |
