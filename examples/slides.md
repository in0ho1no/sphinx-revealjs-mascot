# MyST Markdown の利用例

```{toctree}
:hidden:

fragments
minimal/index
positions
```

## ジャンプで始める

```{mascot}
:action: jump
```

発表のテーマを紹介します。

## 左下で注目を集める

```{mascot}
:action: surprise
:position: bottom-left
```

右側に配置した図を説明します。

## 中心位置を座標で指定する

```{mascot}
:action: idle
:position: 70%, 60%
```

このスライドでは、本文を左側に配置します。
