# 追加アクションの利用例

標準画像には追加状態の画像も同梱しているため、設定なしで追加アクションを使えます。
独自画像では、対応する状態画像を置いたアクションだけを指定できます。

## 問いかける

```{mascot}
:action: tilt
:position: top-right
```

なぜ待ち時間が長くなっていたのでしょうか。

## 失敗談を紹介する

```{mascot}
:action: trouble
:position: bottom-left
```

最初の対策では、かえって処理が遅くなりました。

## 工夫を示す

```{mascot}
:action: proud
```

処理の順序を入れ替え、待ち時間を半分にしました。

## 段階表示で反応を変える

結果をまとめます。

```{mascot-fragment}
:action: proud

待ち時間を半分にできました。
```

```{mascot-fragment}
:action: tilt

ただし、まだ改善の余地があります。
```

## 感謝を伝える

```{mascot}
:action: happy
:position: top-left
```

ご清聴ありがとうございました。
