# 表示位置とモーションの確認

## 左上

```{mascot}
:action: jump
:position: top-left
```

ジャンプ中の上端と、ウトウト中の傾きを確認します。

## 右上

```{mascot}
:action: jump
:position: top-right
```

左上と同様に見切れず、中央側へ傾くことを確認します。

## 左下

```{mascot}
:action: surprise
:position: bottom-left
```

呼吸・揺れ・驚きの動きが、画面内に収まることを確認します。

## 右下

```{mascot}
:action: surprise
:position: bottom-right
```

左下と動きを見比べます。「Zzz」は読める向きを保ちます。

## 中央

```{mascot}
:position: 50%, 50%
```

四隅と同じ表示幅で、元画像の向きに戻ることを確認します。

## 画面端の任意座標

```{mascot}
:position: 0%, 0%
```

任意座標では、指定した中心位置から画像の一部が画面外に出ることを許容します。
